# Loops and menus

> The commands and patterns from this unit. In the tutorial, open **Reference** in any playground to copy them.

:::keep-together

**while loop**: Repeat the indented lines for as long as the condition is true.

```python
while True:
    pass
```

:::

:::keep-together

**def (function)**: Name a group of steps, then run it by calling its name.

```python
def shape():
    pass

shape()
```

:::

:::keep-together

**random number**: Pick a random whole number between two values.

```python
import random

n = random.randint(1, 10)
```

:::

:::keep-together

**add to (+=)**: Add to a variable: total += 5 is short for total = total + 5.

```python
total += 1
```

:::

:::keep-together

**break**: Leave the loop straight away; the program carries on after it.

```python
break
```

:::
